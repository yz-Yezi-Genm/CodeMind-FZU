流程图说明 Agent 如何完成一次政策咨询；时序图说明学生端、Agent、领域知识库、Tavily 和 LLM 之间的消息传递；集成说明阐述 Agent 在软件系统中的位置，以及领域知识、工具调用和任务流程的作用。

三项正式成果已对齐 [`../architecture/技术架构设计说明_赵紫龙_v1.md`](../architecture/技术架构设计说明_赵紫龙_v1.md)：单体 FastAPI、Chroma + BM25 + RRF、生成前 `EvidenceVerifier`、`LLMAdapter / Qwen API`、生成后 `AnswerVerifier` 以及 `AnswerComposer` 的职责和调用顺序保持一致。

v1.1 根据 PR #7 审核意见进一步明确：`LLMAdapter` 位于 FastAPI 内部、Qwen API 是外部模型服务；UML 时序图分别展示 Chroma 与 BM25 两路并行召回，并在两路返回后执行 RRF 融合；同时增加学生参与者左侧画布边距。

后续审核修订明确最终返回链为 `AnswerComposer → AgentOrchestrator → FastAPI /api/ask → Web 前端`，并将 `AnswerVerifier → AnswerComposer` 固定为单向调用。

v1.2 根据最新复核意见，将 `EvidenceVerifier → AgentOrchestrator` 的核验结果返回、`AgentOrchestrator` 的生成决策、`Tavily → EvidenceVerifier` 的查询结果返回，以及 `Ask API → Web 前端` 的 HTTP 响应全部改为独立有向边；Draw.io、SVG 与 PNG 已同步。
