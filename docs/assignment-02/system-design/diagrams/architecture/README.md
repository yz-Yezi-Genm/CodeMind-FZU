# 系统架构图

负责人：赵紫龙（v1.0 已完成，待成员本人提交与交叉评审）。

本目录包含 CodeMind-FZU 面向首版实现的总体技术架构。架构遵循第一次开题答辩稿已经确定的方案：HTML/CSS/JS Web 入口、FastAPI 后端、Agent 编排、本地知识库、Chroma + BM25 + RRF 混合检索、Qwen API 生成和候选 Tavily 联网核验。

> 说明：除仓库现有知识库资料、Figma 原型和离线 PoC 外，真实 Qwen 调用、混合检索效果、正式资料接入和完整系统联调尚未完成。

## 关键约束

1. v1.0 采用单体 FastAPI 应用承载接口与 Agent 编排逻辑，不以独立微服务为交付前提。
2. 本地资料优先；Chroma 与 BM25 双路召回后使用 RRF 融合。
3. Qwen API 只基于筛选后的证据组织答案，API 密钥不得进入前端或仓库。
4. Tavily 是候选能力，联网结果必须回到官方原文核验。
5. 证据不足、规则冲突、模型超时或引用校验失败时必须保守降级。
6. 数据库、完整 Web 管理端、会话持久化和个性化推荐属于后续阶段。
7. 知识库项目基准为 44 条；当前仓库 CSV 的 31 条仅表示现有索引记录数，二者不能直接等价。
