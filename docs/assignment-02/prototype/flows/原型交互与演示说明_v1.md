# 原型交互与演示说明

整理人：洪添军。版本 v1。页面设计分别由吴欣键、林彦翔完成。

## 展示范围

首版演示围绕校园信息查询、来源依据、当前会话追问、资料补充和后台资料维护展开。任务规划与执行、登录注册、个人档案、模型切换、导出等依学生端 README 标为后续迭代。页面中的政策、来源、回答和处理状态均为交互示例。

## 演示顺序

以下为约 4 分钟的核心演示路线。完整展示范围见 [学生端完整流程索引](学生端完整流程索引_v1.md)，其中覆盖全部 52 个学生端页面和弹窗，并将后续迭代独立标注。需要展示全部功能时，可按索引逐组打开对应图片及画板。每组编号表示阅读顺序，具体跳转参考该组交互清单。

1. 用原型总览介绍学生查询与管理维护两个角色，约 20 秒。
2. 从学生端首页点击政策与事务办理卡片，进入 04 奖学金咨询，点击开始检索并生成建议。05 检索页配置了 1.8 秒后进入 06 结果页，也可点击查看演示结果。点击展开 3 条来源进入 08，返回回答后点击继续补充细节进入 11，约 70 秒。
3. 打开 03 资料不足，点击补充信息并重新检索，打开 49 补充背景弹窗，点击补充并继续检索进入 35 补充后的结果，约 40 秒。
4. 单独打开管理员入口，从 A25 进入资料审核 A26，点击资料行进入 A27。点击编辑资料进入 A37，保存后展示生成待审核版本的提示。关闭提示、返回详情，再演示通过并发布及发布成功弹窗，约 70 秒。
5. 展示学生回答反馈表单，再切换管理员入口展示 A35 反馈处理，约 30 秒。两个角色分别演示，现有归档未验证同一反馈的跨端数据同步。
