# 后台管理原型

负责人：林彦翔

Figma 在线原型：https://www.figma.com/design/Wan3sZFRzZyAo8JtW3olYV/agent%E5%8E%9F%E5%9E%8B

本目录为后台管理端原型，共 15 个页面 + 5 个交互弹窗，覆盖管理概览、资料审核、资料编辑、用户管理、角色权限、数据来源、运行记录、反馈与审计等管理动作。截图位于 `screenshots/`，均由 Figma 可编辑画板导出。

## 页面清单

| 编号 | 页面 | 功能说明 | 截图 |
|---|---|---|---|
| A25 | 管理概览 | 待办事项看板：汇总待审核资料、待处理数据申请、待处理反馈，点击进入对应处理页 | A25_管理概览.png |
| A26 | 资料审核 | 知识库资料列表：搜索、状态筛选（全部 / 待审核 / 已发布 / 已退回），待审核排前 | A26_资料审核.png |
| A27 | 资料详情与审核 | 核验资料原文、来源与所述信息，通过并发布 / 退回，并可查看审核记录 | A27_资料详情与审核.png |
| A37 | 资料编辑 | 两列表单：标题、来源单位、文号、类型、发布日期、生效日期、适用范围、适用人群、时效、来源链接、附件、备注；支持保存草稿与提交审核 | A37_资料编辑.png |
| A31 | 用户管理 | 账号列表与搜索，进入用户详情 | A31_用户管理.png |
| A32 | 用户详情 | 用户基础信息、数据申请处理入口、账号操作（停用 / 恢复） | A32_用户详情.png |
| A38 | 用户编辑 | 修改用户身份信息：学院、专业、年级、角色、状态（在校）、联系方式 | A38_用户编辑.png |
| A33 | 角色与权限 | 系统管理员 / 资料维护员 / 只读运营 的权限矩阵 | A33_角色与权限.png |
| A33b | 权限管理态 | 编辑态：权限值黑色显示、每格带下拉箭头，可调整 | A33b_权限管理态.png |

| A36 | 操作审计 | 管理员操作留痕：账号、资料、权限变更的记录 | A36_操作审计.png |
| A29 | 运行与反馈 | Agent 任务运行轨迹：步骤、工具调用与结果，按最小必要范围展示 | A29_运行与反馈.png |
| A30 | 运行详情 | 单个任务的运行详情与工具调用记录 | A30_运行详情.png |

## 补充说明

- 「用户详情 → 处理申请」会弹出数据删除申请弹窗，提供「取消 / 拒绝处理 / 确认处理」三个动作。
- 示例数据均为虚构演示数据（王小明、U-1001、ADM-001 等），不包含真实同学信息。
- 状态不以颜色单独表达，均同时给出文字（待审核 / 已发布 / 已退回 / 待处理 / 在校 等）。
- 资料编辑字段与知识库实际字段对齐（来源、文号、类型、日期、适用范围、人群、时效、来源链接、附件）。
- 原型中的模型回答、文件解析、导出、认证与数据库操作尚未接入真实服务。
