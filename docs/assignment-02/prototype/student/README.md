# 学生端原型

## v1.0 与后续迭代

截图编号沿用 PR #9 的归档编号。[页面索引与 Figma 链接](./学生端页面说明.md)可用于定位画板。

| 版本 | 截图编号 | 功能范围 |
| --- | --- | --- |
| v1.0 | 01–06、08–11、29–33、35、46、49、51 | 四类校园信息查询、当前会话内追问、检索和来源展示、证据不足提示、补充必要背景、反馈。02 展示学院科研入门资源，09 展示推免基本条件，29 仅确认学院和适用届次。 |
| v1.0 | 16–18、39–41、50、52 | 公共资料检索、检索记录及当前会话临时文件解析。学生上传内容不会自动进入管理员维护的公共知识库。 |
| 后续迭代 | 07、12–15、19–28、34、36–38、42–45、47–48 | 个性化规划、任务执行与跟踪、成果与待办、持久化个人资料库、登录注册、个人档案及跨会话记忆、模型切换、导出、代码执行和任务通知。 |

首版只使用本次查询所需的临时背景。推免查询展示政策条件、适用范围和出处，个人资格由学校和学院按实际规则认定。画板中的政策、来源和检索结果为交互示例。

首版模型以实际 Qwen API 配置为准，模型选择画板属于后续概念展示。代码执行和高级工具管理也属于后续扩展。管理工作台只对具备后台权限的用户开放，普通学生画板已隐藏其入口。
