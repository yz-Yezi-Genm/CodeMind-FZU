# CodeMind-FZU 学生端原型

负责人：吴欣键

本目录收录学生端页面及交互弹窗。[版本划分见 README](./README.md)。在线演示入口见 [Figma 原型](https://www.figma.com/proto/Wan3sZFRzZyAo8JtW3olYV/agent%E5%8E%9F%E5%9E%8B?node-id=9-40)。

- 01–24：从首页发起咨询，查看检索、回答与依据，规划和执行任务，管理资料、历史及设置。
- 25–37：登录、注册、访客体验、保研与竞赛场景、资料补充、成果与待办。
- 38–52：模型与范围选择、上传、导出、反馈及相关交互弹窗。
