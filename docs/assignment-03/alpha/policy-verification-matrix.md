核验日期：2026-11-19。本轮在已合并的文档解析成果上复核竞赛认定、奖学金、推免三个场景；公共接口及原有生成脚本不变。

## 统计口径与结论

本轮涉及 **5 份通知/办法及其附件**，不是重新统计全部 44 条资料。三份竞赛 DOCX 作为附件核验项单列，形成下面的 **8 个主要核验对象**，不新增原清单的业务资料编号。

- 5 个通知网页：4 个本轮成功获取，且与既有归档字节一致；竞赛通知页跳转统一身份认证，当前联网核验未完成。
- 6 个附件请求：三份竞赛 DOCX、推免 PDF、院级奖学金 ZIP、星火 RAR 均从官方公开下载地址取得。其中 ZIP/RAR 的表单内容尚未可靠解析。
- 生成 **5 份候选 DocumentPackage、371 个片段**：3 份 `review_only`、2 份 `blocked`。**人工签核通过 0 份，enabled 0 份**。
- 来源核对、文本覆盖与版式对照由工具及 AI 完成；没有冒充人工审批。`source_verification_status=verified` 仅表示本轮来源核对通过，不能替代政策时效、附件完整性或人工语义审核。
- 五份包均通过公共模型校验、文件哈希检查和现有本地 BM25 离线索引检查；正式问答检索返回 0 条，符合当前限制。这不代表生产入库或正式问答效果验收完成。

## 容易混用的条件

| 内容 | 核对结果及限制 |
|---|---|
| 竞赛附件的合并单元格与脚注 | 三份 DOCX 分别检查 OOXML 的 `gridSpan`、`vMerge`，本批均为0；脚注/尾注实际正文为0，表格“备注”列完整保留。此结论仅针对这三份文件，不表示所有政策附件都无合并或脚注。205条数据共检查834个非空单元格（含表头），均能在已有提取稿中找到对应文本；不等同逐条人工审定。 |
| 竞赛认定与综评 | 教务处2026目录确定竞赛级别/相关认定用途；2027届推免计分表仅服务该届推荐资格；均不能直接替代学院日常综合素质测评加分细则或文化科技创新创业奖学金目录。 |
| 学校综合奖学金 | 原文第七条的1500/1000/500元是每人每学期标准；前10%/20%/40%是相应排名门槛。实验班、非实验班的获奖比例另有规定，两者不能混为同一种比例。 |
| 处分条件 | 学校办法第五条涉及评定学期内受警告及以上处分且仍在处分期内等情形；学院通知要求在校期间未受过任何处分。不得跨文件合并成一套通用条件。 |
| 学院奖项 | 院级通知列出星火、UPTOP、爱国者之星、荣耀计算机等名称；具体类别金额和对象以原通知对应行及专项条文为准，年度未确认前禁止正式检索。 |
| 星火教师/学生 | 教师奖教金16人、5000元；学生奖学金30人、4000元。每个片段保留所属“星火奖教金”或“星火奖学金”细则标题，避免孤立数字串造成混用。 |
| 推免第4页 | 国际级、国家级分开；个人、集体分开；国家级三等奖集体为1.5分。保留团体排名系数、非四舍五入的原说明；志愿服务边界和原文标点问题交人工释义，不修写政策。 |

1. 在校园网/用户自行登录后复核竞赛通知正文、日期与三附件关联；保留可审计来源。当前不提供该页已联网通过的结论。
