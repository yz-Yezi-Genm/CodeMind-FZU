# 福州大学本科生综合素质评价实施办法（2026版）

## 适用范围

- 适用于全校全日制在校本科生，包括大一至大四。
- 每学期评价一次，在新学期开学之日起30个自然日内完成上一学期评价。
- 评价结果用于评奖评优、奖学金评定、推优入党、推免、就业推荐和学生骨干选拔。
- 自2026年9月1日起施行，2021版办法同时废止。

## 计算公式

综合素质评价成绩 = 学业测评成绩×80% + 德育素质测评成绩×6% + 智育素质测评成绩×5% + 体育素质测评成绩×3% + 美育素质测评成绩×3% + 劳育素质测评成绩×3% - 负面评价分。

学业测评成绩为“（平均学分绩点＋5）×10”，范围为当学期除校选课外的课程。德育、智育、体育、美育、劳育五项均为100分，由基础性测评70分和发展性测评30分组成。

## 五育和扣分重点

- 德育包括班级互评、辅导员评价、思想品德活动、社会工作、学生活动和荣誉。
- 智育包括学术活动、学科竞赛、创新实践、专利、科研成果和论文。
- 体育包括体育必修课、健康跑、福大体育APP、体育活动和竞赛。
- 美育包括艺术展览、文艺演出、文化艺术创作和竞赛。
- 劳育包括宿舍卫生、志愿服务、劳动教育、技能证书和专业技能实践。
- 通报批评、纪律处分、课堂秩序、宿舍卫生安全和校园交通违规按参考细则扣分。
- 加分项目应为上一学期取得、以福州大学为第一署名单位，并提供证书、公示页面或组织证明。

具体加分项目还要结合《本科生综合素质评价参考细则》和学院实施细则。
